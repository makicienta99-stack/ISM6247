# Product photos

Put your real Kamahe Allegro photos here (square images look best, e.g. 1080x1080 from Instagram).
Then open `shop.js` and set the `photo` field of the product, for example:

```js
photo: "images/products/andes-hoodie.jpg",
```

To use your real Instagram logo, save it as `images/logo.png` and change `images/logo.svg` to `images/logo.png` in `index.html`.
